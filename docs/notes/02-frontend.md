# Babylon.js + Vue3 + Bootstrap5 フロントエンド セットアップ指示書

このファイルは、素の Hono サーバー（`public/` 静的配信 + APIのみ）に、Babylon.js の3D立方体を表示する Vue3 + Bootstrap5 製フロントエンドを追加するための単体の指示書です。このファイル単独で読んで実行できるように書かれています（他ドキュメントの参照は不要です）。

バックエンド側の MQTT 連携・Code Engine への環境変数注入は `03-env.md` のスコープです。このファイルはフロントエンド（`public/index.html`）と、フロントが呼び出す2つのAPIエンドポイント（`POST /api/led/on` / `POST /api/led/off`、実体は `03-env.md` で実装する）の呼び出し方のみを扱います。

## 前提

- Node.js + Hono による静的配信サーバー（`serveStatic({ root: './public' })`）がすでに動いている。
- ビルドパイプラインは導入しない。Vue3 / Bootstrap5 / Babylon.js はすべて CDN 経由の `<script>` タグで `public/index.html` から読み込む。webpack/vite 等のバンドラ、npm 経由のフロントエンドパッケージ導入は行わない。
- CDN のバージョンは `latest` のような不定指定ではなく、明示的にピン留めする。以下は動作確認済みのバージョン:
  - Bootstrap: `5.3.3`
  - Vue: `3.4.21`（グローバルビルド `vue.global.prod.js`）
  - Babylon.js: `6.49.0`（`https://cdn.babylonjs.com/babylon.js`）

## 画面構成

- Canvas 全面に Babylon.js シーンを描画する（`position: fixed` で背景に敷く）。
  - 1×1×1 の立方体。初期色は灰色。
  - 立方体は自転（回転）した状態がデフォルト。
  - カメラは `ArcRotateCamera`。初期状態で立方体を注視する。
  - マウスホイールでズームイン/アウトできる。
  - マウスドラッグでカメラを回せる（`camera.attachControl` を使う）。
- Canvas の上に Vue3 の `#app` をオーバーレイする（コンテナ自体は `pointer-events: none`、実際のUI要素だけ `pointer-events: auto` にして、Canvas 側のドラッグ操作を妨げないようにする）。
- 左上にハンバーガーボタンを固定表示する（`position: fixed; top: 16px; left: 16px` 目安）。クリックで Bootstrap Offcanvas（左から開くドロワー）を開く。
- ドロワー内に以下を配置する:
  - 「回転」トグルボタン：立方体の自転を止める/再開する。
  - 「アングルリセット」ボタン：カメラの位置/ターゲットを初期状態に戻す。
  - LED状態バッジ（ON: 赤、OFF: グレー）を置くと状態が分かりやすい。

## 立方体クリック時の挙動（トグル）

- 初期状態は off（灰色）。
- off の状態でクリック → `POST /api/led/on` を叩く → 成功したら立方体を赤色にし、状態を on にする。
- on の状態でクリック → `POST /api/led/off` を叩く → 成功したら立方体を灰色にし、状態を off にする。
- 状態（on/off）はフロントエンドのみで保持する（ページリロードで off に戻ってよい。サーバー側に現在状態を問い合わせるAPIは無い前提）。
- API呼び出し中は `requesting` フラグ等で二重クリックを無視し、多重リクエストを防ぐ。
- API呼び出しが失敗した場合（ネットワークエラー、非2xxレスポンス）は、色・状態をクリック前のまま維持する（楽観的更新はしない）。エラーはトースト等で一時的に表示する（例: 5秒後に自動で消す）。

## Babylon.js ↔ Vue3 の連携方法（実装しやすい方式）

CDN構成でリアクティブな双方向バインディングを厳密に組むより、シンプルなグローバル変数越しの連携で十分に実用的だったので、この方式を推奨する:

- 自転の停止/再開: `window.__vueRotating` のようなフラグを Babylon のレンダーループから毎フレーム参照する。
- クリック時の処理: `window.__vueApp = { onBoxClick }` のように Vue 側の関数をグローバルに公開し、Babylon の `ActionManager`（`OnPickTrigger`）からこの関数を呼び出す。
- カメラ・立方体メッシュはモジュールスコープの変数として保持し、「アングルリセット」ボタン押下時に Vue 側から直接 `camera.setPosition(...)` 等を呼んで初期状態に戻す。
